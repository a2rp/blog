# a2rp Journal

A focused React blog for clear, practical essays about software, the web, privacy, and everyday digital life.

![a2rp Journal preview](screenshot.png)

## Features

- Searchable posts with tag filters and date sorting
- Responsive desktop navigation and mobile menu
- Dark and light themes with saved preference
- Lazy-loaded article pages with related navigation
- Local images and GitHub Pages deployment

## Tech stack

React, Vite, React Router, styled-components, Material UI, and React Icons.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`. Deploy with `npm run deploy`.
